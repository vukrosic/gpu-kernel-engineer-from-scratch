# Recovery System

This course is a year long. Falling behind is expected. Quitting is optional.

## Do Not Turn Recovery Into Procrastination

Recovery is for getting back into motion. It is not permission to tell yourself,
"I will learn all of this next week," every week.

That habit is dangerous because GPU programming compounds:

- Week 2 assumes you understand the Week 1 baseline.
- Reductions assume you understand indexing and memory.
- Matmul assumes you understand tiling and synchronization.
- Attention assumes you understand softmax, matmul, and memory reuse.

Delaying one hard concept for a day is normal. Delaying the same concept for a
whole week usually means you need to shrink the task, not postpone it.

Good delay:

- "I am tired today, so I will do the Minimum assignment tomorrow."
- "I will skip Stretch work and make the simple version correct."
- "I will use checkpoint week to clean up this benchmark."

Bad delay:

- "I do not understand this, so I will start fresh next week."
- "I will watch more videos instead of running the code."
- "I will optimize later even though I have not made it correct yet."

If you feel resistance, reduce the assignment until it has three pieces:

1. run one command
2. make one small thing correct
3. write one sentence about what happened

## The Priority Stack

When time is limited, do work in this order:

1. understand the concept
2. make the code correct
3. add one test
4. make one benchmark run
5. optimize
6. polish the portfolio note

Never optimize broken code.

## If You Miss One Day

Use Day 6 to catch up. Do not double the next day unless you have the energy.

## If You Miss Two Days

Skip Stretch work. Finish the Minimum assignment:

- correct code or reference implementation
- one test or manual correctness check
- one paragraph explaining the lesson

## If You Miss A Week

Do the checkpoint version:

- read the lesson summary
- run the reference code
- write what you understand and what is still unclear
- move to the next week

Do not try to rebuild the entire missed week unless it is a prerequisite for the
next assignment.

## If You Miss A Month

Restart at the next monthly checkpoint. Your task is to rebuild momentum:

- run the repo
- read the monthly summary
- complete the minimum viable month
- continue with the current cohort

## Minimum Viable Assignment

Every week can be reduced to:

- one correct thing
- one measured thing
- one explained thing

That is enough to stay in the story.
