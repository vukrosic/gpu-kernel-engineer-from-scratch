# Resume Bullets

- Built a GPU-kernel education repo spanning 48 weekly lessons, with CPU reference implementations, CUDA starter kernels, and Triton kernels for vector addition, reduction, softmax, matmul, LayerNorm, and attention pieces.
- Designed benchmarkable kernels and documented the path from reference Python to optimized GPU/Triton implementations with reproducible result notes and monthly checkpoints.
- Added a public-facing project structure with benchmark scaffolding, result templates, and interview-ready explanations for GPU memory behavior, tiling, fusion, and transformer-adjacent kernels.
