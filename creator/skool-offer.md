# Skool Community Offer

The free GitHub repo gives the roadmap, assignments, starter code, and portfolio
structure.

The paid Skool community should sell help finishing the roadmap, not access to
basic information.

## Paid Value

Members pay for:

- accountability to keep going for the full year
- office hours for setup, kernel bugs, benchmark confusion, and roadmap questions
- portfolio reviews for repos, README files, benchmark tables, and writeups
- assignment feedback and implementation review
- monthly checkpoint sessions
- resume bullet and interview-answer reviews
- community comparison: seeing how other builders solved the same assignment

## What Members Learn There

The community should reinforce the course with:

- weekly assignment threads
- debugging channels for CUDA, Triton, PyTorch, and environment setup
- benchmark review posts
- portfolio teardown sessions
- mock interview prompts
- monthly "ship your artifact" accountability checkpoints
- bonus sessions on AMD ROCm, other accelerators, papers, and production stories

## How The GitHub Repo Sends People To Skool

Use soft calls to action where the learner naturally feels friction:

- README Community section
- Week files after the Done Checklist
- Recovery system when someone falls behind
- Portfolio rubric when they need feedback
- Assignment pages when they need implementation review

Do not gate the roadmap. Gate the support, review, accountability, and community
experience.

## Positioning

Free:

```text
Follow the roadmap and build the portfolio.
```

Paid:

```text
Get help finishing it, debugging it, polishing it, and explaining it like an AI
systems engineer.
```

## Bonus Ecosystem Strategy

CUDA and Triton stay as the core course. Skool is a good place to explore wider
topics without bloating the main repo:

- AMD ROCm comparison sessions
- Apple Metal overview
- Huawei/Ascend and other accelerator landscape discussions
- portability lessons
- "how this concept transfers" posts

These are valuable as advanced discussions, but they should not distract from
the main promise: build a strong GPU kernel engineering portfolio.
