# Creator Workflow

This folder keeps the YouTube course sustainable.

## Public Promise

```text
In 12 months, build a public GPU kernels portfolio that proves you understand
CUDA, Triton, performance engineering, and AI kernel optimization.
```

Use salary and career aspiration in titles carefully, but keep the actual course
serious: kernels, benchmarks, explanations, and portfolio proof.

## Weekly Publishing Loop

- Monday: flagship lesson.
- Wednesday: short systems explainer.
- Friday: portfolio review, career video, benchmark breakdown, or community update.

## Anchor Video

Start the course launch with the 50-minute roadmap video:

- [roadmap-video-plan.md](roadmap-video-plan.md)

## Flagship Video Requirements

Each flagship video should include:

- career or systems hook
- mental model before code
- kernel or experiment walkthrough
- correctness check
- benchmark interpretation
- 7-day assignment plan
- recovery path for busy learners

## Side Content Lanes

Use side content to keep the channel fresh without splitting the brand:

- transformer systems explainers
- CUDA/Triton debugging clips
- benchmark breakdowns
- portfolio and resume videos
- interview question walkthroughs

Avoid launching a full parallel Transformers From Scratch course until this GPU
kernel series has a stable production rhythm.
